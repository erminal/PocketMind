这个管理台能改什么

顶部「保存所有修改」会写 data/settings.json 并热重载；人格单独保存。
API / 模型
供应商、Base URL、模型型号、Key、思考开关、温度/最大 token；可在线拉模型、可测试连通。
人格 / Prompt
姓名、年龄、性别、物种、价值观、性格、边界、知识边界、补充 Prompt；可预览完整系统提示词。
记忆参数
检索权重、记忆门、去重、打分、半衰期、遗忘阈值、关系步长、回忆奖励；每项带问号说明。
数据
记忆/事件/消息/检索日志/关系/印象/日记/内心话/标注/媒体/核心事实；可搜索、导出 CSV。
安全提示：API Key 以明文保存在本机 data/settings.json（已被 gitignore）；不要把该文件或截图发给别人。服务只监听 127.0.0.1。

主对话 / 记忆抽取模型

OpenAI 兼容接口；DeepSeek 默认关闭 thinking（快速档）。改完点右上角保存。

Embedding（向量）模型

用于语义检索；不填 Key 时自动用关键词兜底（mock 哈希向量）。

人格身份

这些字段会直接进系统提示词。年龄是**心智年龄**；开启「生日自动增长」后，每经过一次生日当前展示年龄 +1。性别/物种大改时，建议勾选「另存为新角色」做隔离。

Prompt 模板（data/prompt_template.md）

模板是外部数据，不写死在代码里；保存后下一轮对话生效，不需要重新打包。用 {{name}} 这种双花括号占位符。身份基线/名字是必需项，建议保留。
模板里没放的占位符，对应内容就不会注入；例如删掉 {{custom_section}}，补充 Prompt 就不会生效。完整说明见右侧占位符。
